# Quick

**Quick** is a lightweight and efficient post-it note app designed to help you stay on top of your tasks. It offers a simple, intuitive interface to jot down tasks quickly and stay organized.

## Features

- Create, edit, and delete notes effortlessly.
- Timer to help you stay focused and manage your tasks.
- Minimalist design to keep you focused.
- Runs in the background, so your tasks are always accessible.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AmoghJambekar/Quick.git
2. Open the project in Xcode and build the app.
3. Run the app on your simulator or device.

## Usage
Create a note: Add a note by adding it into the box

Edit/Delete notes: Easily modify or remove tasks.

Set a timer: Use the built-in timer to stay focused on your tasks.

Backgrounded: The app runs in the background, keeping your tasks accessible at all times.
